## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mohamedmonge58-create/movies_app
   ```

2. Navigate to the project directory:

   ```bash
   cd movies_app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
